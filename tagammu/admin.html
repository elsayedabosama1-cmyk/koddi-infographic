تسجيل الدخول

الدخول بمفتاح GitHub خاص بك. بيتخزّن على هذا الجهاز بس، ومتشاركوش مع حد.

  1. افتح صفحة إنشاء مفتاح وسجّل دخول.
  2. اكتب أي اسم (مثلًا: إدارة التطبيق) وحدّد مدة انتهاء.
  3. في Repository access اختار Only select repositories ثم koddi-infographic.
  4. في Permissions ← Repository permissions اختار Contents: Read and write.
  5. اضغط Generate token وانسخ المفتاح والصقه هنا.
